# Smart Parking Management System

## Project Overview
The Smart Parking Management System is a C++ based project designed to manage parking slots and vehicle records through a simple console interface.

## Features
- Display all parking slots
- Park a vehicle in an available slot
- Remove a vehicle from a parking slot
- Check available parking spaces
- Count total parked vehicles
- Menu-driven interface

## Technologies Used
- Programming Language: C++
- IDE: Code::Blocks

## Concepts Used
- Functions
- Arrays
- Pointers
- Loops
- Conditional Statements
- Switch Statements

## How to Run
1. Download or clone this repository.
2. Open `main.cpp` in Code::Blocks.
3. Build and run the program.
