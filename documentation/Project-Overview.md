# Project Documentation

## 1. Introduction
The Smart Parking Management System is a C++ console-based application developed to manage parking slots and vehicle records.

## 2. Objectives
- Manage five parking slots.
- Park vehicles in available slots.
- Remove vehicles from occupied slots.
- Display parking slot status.
- Count available slots and parked vehicles.

## 3. System Features
1. Display Parking Slots
2. Park Vehicle
3. Remove Vehicle
4. Check Available Slots
5. Count Total Parked Vehicles
6. Exit System

## 4. Technologies Used
- C++
- Code::Blocks IDE

## 5. Programming Concepts
- Arrays
- Pointers
- Functions
- Loops
- Conditional Statements
- Switch Statements

## 6. Conclusion
This project demonstrates the use of fundamental C++ programming concepts to develop a simple parking management application.
